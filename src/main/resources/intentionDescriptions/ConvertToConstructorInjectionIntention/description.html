Converts field injection to constructor injection: every @Autowired or @Inject field in the class becomes a final constructor parameter assigned in the constructor. A new constructor is created after the last field, or the existing single constructor is extended. A @Qualifier on the field travels to the parameter.

Fields that are not moved: @Resource (name-based lookup), @Value (configuration, not bean injection), static fields and fields with initializers. The action is not offered for enums, for classes with a Lombok @RequiredArgsConstructor, or when several constructors already exist and the choice of target would be ambiguous.

Constructor injection keeps dependencies immutable and makes classes testable without a Spring context — this is the style the Spring team recommends for new code.
